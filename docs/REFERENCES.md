# Dart — Curated References & Further Reading

Compiled for ICS 410 (Programming Languages) Spring 2026. All URLs verified live; all material post-Dart 2.12 (sound null safety era).

## Official Documentation

- **[Introduction to Dart (Language Tour)](https://dart.dev/language)** — *Beginner / Intermediate* — Example-driven tour of every major Dart feature; the canonical starting point.
- **[Effective Dart](https://dart.dev/effective-dart)** — *Intermediate / Advanced* — Google's official style, documentation, usage, and design guides built on DO/DON'T/PREFER/AVOID rules.
- **[Dart API Reference](https://api.dart.dev)** — *Intermediate / Advanced* — Generated docs for `dart:core`, `dart:async`, `dart:io`, `dart:ffi`, and platform interop libraries.
- **[What's New (Release Notes)](https://dart.dev/resources/whats-new)** — *All levels* — Tracks every Dart SDK release.
- **[Dart 3 Migration Guide](https://dart.dev/resources/dart-3-migration)** — *Intermediate / Advanced* — Covers sound null safety, class modifiers, removed APIs, and tool consolidation.
- **[pub.dev](https://pub.dev)** — *All levels* — Official package registry for Dart and Flutter.

## Tutorials & Free Courses

- **[Dart Tutorial - Build a CLI app](https://dart.dev/tutorials)** — *Beginner* — Official interactive tutorial: build a CLI program from scratch.
- **[Dart and Flutter Codelabs](https://dart.dev/codelabs)** — *Beginner / Intermediate* — Combined Dart fundamentals + Flutter pathway with hands-on codelabs.
- **[Patterns and Records Codelab](https://dart.dev/codelabs/dart-patterns-records)** — *Intermediate* — Applied codelab on Dart 3's destructuring/pattern matching.
- **[freeCodeCamp - Dart articles & full course](https://www.freecodecamp.org/news/tag/dart/)** — *Beginner* — 40+ free articles plus a full Dart programming video course.
- **[Code with Andrea (YouTube)](https://www.youtube.com/@codewithandrea)** — *All levels* — Andrea Bizzotto, Google Developer Expert; deep Dart/Flutter playlists.
- **[The Net Ninja (YouTube)](https://www.youtube.com/@NetNinja)** — *Beginner / Intermediate* — Clear, beginner-friendly Dart and Flutter playlists.

## Books

- **[Dart Apprentice: Fundamentals (Kodeco, 2022)](https://www.kodeco.com/books/dart-apprentice-fundamentals)** — *Beginner* — Jonathan Sande; covers variables, control flow, classes, nullability. Post-null-safety.
- **[Dart Apprentice: Beyond the Basics (Kodeco)](https://www.kodeco.com/books/dart-apprentice-beyond-the-basics)** — *Intermediate / Advanced* — Mixins, generics, async programming, isolates, error handling.
- **[Flutter Apprentice, 4th Ed. (Kodeco)](https://www.amazon.com/Flutter-Apprentice-Fourth-Learn-Cross-Platform/dp/195032592X)** — *Intermediate* — Applied Dart through cross-platform Flutter app building.
- **[The Complete Dart Developer Guide (Andrea Bizzotto)](https://codewithandrea.com/courses/complete-dart-guide/)** — *Beginner / Intermediate* — 17 modules / 10 hrs video + free eBook; very current.

## Articles & Blogs on Key Topics

- **[Understanding Null Safety](https://dart.dev/null-safety/understanding-null-safety)** — *Intermediate / Advanced* — Deep dive into flow analysis and design rationale by the Dart team.

- **[Patterns documentation](https://dart.dev/language/patterns)** — *Intermediate* — Pattern matching, destructuring, JSON validation examples (Dart 3+).
- **[Records documentation](https://dart.dev/language/records)** — *Intermediate* — Immutable aggregate types for multi-value returns.
- **[Asynchronous programming: futures, async, await](https://dart.dev/libraries/async/async-await)** — *Beginner / Intermediate* — Official async tutorial with DartPad-runnable examples.
- **[Announcing Dart 3 (Official Dart Blog)](https://blog.dart.dev/announcing-dart-3-53f065a10635)** — *All levels* — Michael Thomsen's launch post on records, patterns, 100% sound null safety.
- **[The road to Dart 3](https://blog.dart.dev/the-road-to-dart-3-afdd580fbefa)** — *Intermediate* — On the null-safety completion journey.

## Tools

- **[DartPad](https://dartpad.dev)** — *All levels* — Browser-based Dart playground; no install required. Ideal for live tutorial demos.
- **[Tools overview](https://dart.dev/tools)** — *All levels* — Index of `dart` CLI, DevTools, IDEs, and `webdev`.
- **[Dart VS Code Extension](https://marketplace.visualstudio.com/items?itemName=Dart-Code.dart-code)** — *All levels* — 14M+ installs; debugging, hot reload, completion.
- **[`dart analyze`](https://dart.dev/tools/dart-analyze)** — *Intermediate* — Static analysis CLI mirroring IDE diagnostics.
- **[`dart format`](https://dart.dev/tools/dart-format)** — *Beginner* — Auto-formatter aligned with Effective Dart style.
- **[`dart fix`](https://dart.dev/tools/dart-fix)** — *Intermediate* — Applies bulk automated migrations and lint fixes.
- **[pub.dev (registry)](https://pub.dev)** — *All levels* — Discover, score, and publish packages.

**Legacy flag:** No pre-2.12 (March 2021) references are included. Anything written before then assumes non-null-safe Dart and should be avoided unless studying language history.
